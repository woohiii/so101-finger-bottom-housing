# SO-101 손가락 밑 하우징

SO-101 손목 롤(servo horn) 결합을 위한 3D 프린트용 손가락 밑 하우징입니다.

## 포함 파일

- `손가락 밑 하우징.stl` — 최종 출력용 STL

## 현재 설계

- 원형 하우징 판: 외경 95 mm, 두께 4 mm
- SO-101 결합 패턴: `Wrist_Roll_SO101.stl`의 중앙 및 M3 물방울 윤곽 기준
- M3 홀 중심 간격: 9.899 × 9.899 mm
- 안쪽 M3 물방울 입구: 약 5.247 × 4.320 mm
- 바깥 혼 결합면 M3 관통홀: 3.887 × 3.200 mm
- 안쪽 입구에서 바깥 관통홀까지 테이퍼 깊이: 1.6 mm
- 혼 결합부 외곽 림: 외경 26 mm, 내경 23.6 mm
- 중앙 체결면: 외곽 림 끝보다 2.0 mm 리세스

## 출력 전 확인

1. 슬라이서에서 물방울 패턴의 방향과 M3 홀 4개 위치를 확인합니다.
2. 먼저 얇은 시험 출력으로 SO-101 손목 혼과 나사 체결을 확인합니다.
3. 실제 조립에서는 나사 길이와 혼·프레임 간섭을 반드시 확인합니다.

## 검증

```bash
uv run python - <<'PY'
from pathlib import Path
import struct

p = Path("손가락 밑 하우징.stl")
d = p.read_bytes()
n = struct.unpack_from("<I", d, 80)[0]
print("STL 정상:", len(d) == 84 + n * 50, "triangles:", n)
PY
```

- 이 파일은 설계 검증용입니다. 실물 조립 전 반드시 시험 체결을 권장합니다.
